# 捉虫子 0.6.10：首页飘落与夜间预览

按用户本轮要求覆盖旧版摇动弹起、最大三倍贴纸及外框预览约定。

- 首页25种作物贴纸使用对局同作物尺寸的1～2倍，保留不同尺寸与比例。
- 手机加速度低通提取屏幕平面重力方向，稳定倾斜后持续向该方向缓慢飘落；尖峰、噪声不产生发射冲量。速度有上限，碰撞低弹性，稳定堆叠后休眠，改变倾斜再唤醒。平放时自然减速；后台暂停/解绑，恢复重新采样，离页清理。
- 设置右侧增加44像素返回按钮，直接返回模式首页，不弹出确认。沿用宿主的控制器清理、电脑任务取消与串行保存队列，两模式进度分开保留；重新进入秘密阶段仍确认隐私。
- 双人贪吃虫的选牌及行动阶段，三个寄生作物图片下面单独绘制蓝色柔光，不受图片滤镜覆盖。白天、隐私交接、后台及电脑秘密阶段隐藏。
- 高清行动牌预览裁切为圆角，去掉外框、外框底色及阴影。原框上的牌型标题和规则说明放入牌内下半部，移除预览里的“啃食几次”；缩略手牌的原次数显示保留。所有十/环图形仍按displayInstructions绘制，预览不执行出牌。

素材与地形沿用0.6.9；昼夜共用farm_scene.png、cover裁切与坐标。规则、模型、存档schema5及键、棋盘几何、音乐、原生监听、依赖锁与包名不变。

回归覆盖方向和速度、持续倾斜、尖峰与噪声、堆叠休眠、不同帧率、1～2倍真实作物尺寸、前后台/离页监听、返回首页与进度恢复、夜间光晕隐私及五张预览布局。APK由GitHub Actions构建并逐项校验，实际验证结果记录在APK_0_6_10.json。
