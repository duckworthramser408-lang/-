## 玩法与布局

5×5棋盘，中心梨开局已被啃食；剩余24个作物选择3个固定寄生位置。共6回合，每轮夜间贪吃虫先行动、白天戴夫后标记，两个阶段轮次相同。每轮最多保留3枚本轮标记，待提交可取消，确认后在戴夫行动结束前也可再次点击撤销；未撤销的标记有效至下一夜结束，随后灰色保留历史；只有当前标记限制贪吃虫，普通作物仍可被啃食。

五张行动手牌为环十、环十、环环、十十、环十十，前5轮自由打出未使用牌并从可用手牌中移除（缩略图以暗色保留、不可点击），第6轮复用编号⑤。每个行动使用不同、未被当前标记的贪吃虫，严格校验环/十范围；有效次数=min(牌面次数,可行动虫数)，额外次数作废并公开线索。同一轮找齐全部三个寄生作物立即戴夫胜；无存活普通目标或全部可行动范围无目标也戴夫胜；完成第6白天仍未达条件则贪吃虫胜。两种模式独立存档。

强制竖屏，安全区上2/3棋盘、下1/3操作面板。草地背景使用cover铺满屏幕，25块独立地块与点击层共用自适应坐标，土地间草地不可选；上方操作按钮右侧显示回合数，下半只展示可横滑的卡牌。水印“反馈q2855863989陈”固定在上边缘，不截获触摸；应用未启用FLAG_SECURE截图限制。

## 快速运行与APK

Flutter3.47.6（.flutter-version）、JDK17或21、Android SDK：

```bash
flutter pub get --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --release --no-pub
```

本云环境先执行`source scripts/cloud_env.sh`；工具未准备时执行`bash scripts/bootstrap_cloud.sh`。输出安装包为`build/app/outputs/flutter-apk/app-release.apk`。环境、签名、安卓/卓易通安装步骤见[开发与打包说明](docs/DEVELOPMENT.md)，结果见[验证记录](docs/VALIDATION.md)。[下载捉虫子0.6.8 APK](https://github.com/duckworthramser408-lang/-/raw/29929eb46a1c91f30e3726eec2275b73cd1e56ee/app-release.apk)（约97.3MB）。签名、资源与实际下载核验见[安装包记录](docs/APK_0_6_8.md)。
